# 業務補助ツール PWA版

JAN管理、農薬検索、チェーンソー部品検索、電動工具替刃検索、ホース長さ計算、値入率計算、木材カット図、社内資格トレーニングをまとめた静的Webアプリです。基本機能はローカルで完結し、Progressive Web App（PWA）として端末へ追加できます。現在の版番号は `version.json` を参照してください。

## 主なツール

- JANスキャンメモ
- 農薬適用検索
- チェーンソー部品検索
- 電動工具の替刃・互換検索
- ホース長さ計算
- 値入率計算：仕入値と値入率を個別入力し、小数点以下2桁まで使って販売価格を1円単位で切り上げ
- 木材カット図（試作版）
- 社内資格トレーニング：Anki用CSVを資格ごとに端末へ登録し、FSRS-6で復習時期を調整
- 要望・不具合送信フォーム

各ツールの上部には、操作順を3段階で示す簡易説明と注意事項を表示します。トップ画面の共有ボタンでは、現在公開しているURLのQRコード表示、端末の共有機能、URLコピーを利用できます。QRコードの取得に失敗した場合も、共有機能とURLコピーは利用できます。

## オフライン保存

PWA登録時には、トップ画面・共通処理・アイコンなど、アプリ本体の最小構成だけを保存します。

各ツールはトップ画面のカードにある「オフライン保存」を押した時点で、必要なHTML・CSS・JavaScript・データをツール単位でまとめて保存します。保存していないツールはオンラインでは利用できますが、通信できない状態では開けません。

農薬検索の約29 MBの全件データは、農薬検索本体とは別に「農薬全件データを保存」から追加保存します。新版へ更新すると旧版のツール別キャッシュは削除されるため、必要なツールを再度保存してください。

## 構成

- `service-worker.js`：共通キャッシュ、ツール別キャッシュ、更新制御
- `sw-assets.js`：各ツールと追加データの保存対象一覧
- `version.json`：現在の版番号と公開日
- `assets/share.js`：URL共有、QRコード表示、コピー操作
- `shared/css/tool-guide.css`：共通の操作案内と画面順序調整
- `shared/js/tool-guide.js`：ツール別の操作手順・注意事項
- `shared/js/jan-code.js`：JANの正規化と検証
- `shared/js/ean13.js`：検索結果用バーコードの遅延表示
- `shared/js/pwa-client.js`：PWA登録、インストール、更新通知、個別保存API、操作案内の読込
- `tools/jan-scanner/js/`：JAN保存、カメラ読取、Canvas描画
- `tools/pesticide-search/js/`：園芸用データと追加データの段階読込
- `tools/wood-cut-planner/js/`：木材マスタ、JAN連携、カット計算、画面制御
- `tools/markup-calculator/js/`：仕入値・値入率の検証、販売価格計算、テンキー画面制御
- `tools/qualification-study/`：Anki CSV取込、資格別問題・学習履歴の端末保存、FSRS-6による復習
- `scripts/`：構成検査、データ生成、主要処理の検査

### 社内資格トレーニングの問題登録

Ankiから `Front`、`Back`、`Tags` 列を持つUTF-8のCSVを書き出し、社内資格トレーニング画面の「CSVファイルを選ぶ」から登録します。CSVはサーバーへ送信せず、問題と学習履歴をIndexedDBへ保存します。複数資格を登録でき、同じ資格名で再登録すると同じ問題の学習履歴を引き継ぎます。

FSRSにはOpen Spaced Repetitionの `ts-fsrs` 5.4.1（FSRS-6、MIT License）を使用しています。配布物とライセンスは `tools/qualification-study/vendor/` に同梱しています。

## 版管理と更新手順

版番号にはSemantic Versioning（例：`1.0.1`）を使用します。公開ファイルを変更したら、必ず版番号も更新してください。

```bash
node scripts/bump-version.mjs 1.7.0 "変更内容"
npm run check
```

`bump-version.mjs`は次を同時に更新します。

- `service-worker.js`の`APP_VERSION`
- `version.json`
- `CHANGELOG.md`

版番号を変えると新しい共通キャッシュとツール別キャッシュが作られます。利用中の画面は自動で切り替えず、「新版を利用できます」という通知から更新した時点で切り替わります。

### 版番号の目安

- PATCH（`1.0.0` → `1.0.1`）：誤記修正、データ更新、小さな不具合修正
- MINOR（`1.0.0` → `1.1.0`）：後方互換性を保った機能追加
- MAJOR（`1.0.0` → `2.0.0`）：保存形式や操作方法に互換性がない変更

## 検査

Node.js 20以降で実行します。

```bash
npm run check
```

版番号の一致、共通・ツール別キャッシュ対象、トップ画面のツール登録、HTML内の相対参照、JAN共通処理、JANリスト保存処理、木材カット計算、値入率計算、農薬データ処理を確認します。

## 保守時の注意

- 公開ファイルを変更した場合は、`version.json`と`service-worker.js`の版番号を同時に更新してください（`bump-version.mjs`を使用）。
- ツールの公開ファイルを追加・削除した場合は、`sw-assets.js`の該当ツール配列も更新し、`npm run check`で存在確認してください。
- トップ画面にツールカードを追加した場合は、カードURLのディレクトリ名と `KOMERI_TOOL_ASSETS` のキーを一致させてください。
- 農薬元データを更新した場合は `node scripts/split-pesticide-data.mjs` を実行し、分割ファイルも更新してください。
- 木材商品データは `tools/wood-cut-planner/js/materials.js` で管理し、JAN・寸法・確認日・出典を残してください。
- 販売実績、在庫数などの業務数値、社内限定情報、個人情報、認証情報はリポジトリへ配置しないでください。

## 動作条件

カメラ、Service Worker、PWAインストールは、原則としてHTTPSまたはlocalhostで動作します。カメラ読取は `BarcodeDetector` 対応ブラウザ（Android版Chrome等）が必要で、非対応ブラウザでは手入力になります。木材カット図は試作版です。このサイトは個人制作物であり、所属企業やメーカーの公式サービスではありません。
