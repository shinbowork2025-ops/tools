# 発注数計算

前年30日販売数、現在庫、任意の今年30日販売数から推奨発注数を計算する試作ツールです。

## 計算条件

- リードタイム: 21日
- 発注間隔: 7日
- 保護期間: 28日
- 今年30日販売数が未入力の場合、補正係数は1.00

## 計算式

```text
前年1日平均 = 去年30日販売数 ÷ 30
今年補正係数 = 今年30日販売数 ÷ 去年30日販売数
補正後1日平均 = 前年1日平均 × 今年補正係数
28日需要予測 = 補正後1日平均 × 28
安全在庫 = ceil(z × sqrt(28日需要予測))
推奨発注数 = max(0, ceil(28日需要予測 + 安全在庫) − 現在庫)
```

今年30日販売数を入力しない場合は、今年補正係数を1.00として計算します。

## 注意

このツールは発注数のたたき台を出すためのものです。欠品、特売、売場変更、季節変動、在庫数のずれがある場合は手動で補正してください。
